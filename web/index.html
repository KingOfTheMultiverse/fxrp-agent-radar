Simulated, not on-chain. Every live agent on Coston2 is heavily over-collateralised, so the dangerous end of the curve never appears in real data. This replays the same scoring functions down a degradation path from 's real current state.

How the score works

  • Collateral buffer — headroom above the liquidation threshold, as a fraction of it. 0% means the agent is sitting exactly on the line. Vault and pool are scored separately and the weaker one governs.
  • XRP backing surplus — underlying XRP the agent holds versus what it owes redeemers. If this goes negative, redemption pays out collateral at the default factor instead of actual XRP. A redeemer who wanted XRP does not get XRP.
  • Weighting — 40% collateral safety, 30% backing, 20% capacity, 10% fee. Safety outranks price deliberately: a few basis points of fee never compensates for a failed redemption.
  • Any agent not in NORMAL status scores 0 and is never routed to.
